## [Unreleased]

### Added
- Initial package scaffolding: `pyproject.toml`, `src/` layout, MIT license.
- CI workflow: pytest + ruff + mypy on Python 3.11 and 3.12 (macOS + Linux, CPU only).
- README and CHANGELOG with accurate project status.
- **C0.2 — units module**: `atmos_jax_common.units` ports the exact ppm ↔ molec/cm³ ↔ kg/bag conversions used by `som-tomas-app/src/box.f` (lines 416, 592, 604–605, 805–806). Exposes physical constants (`R = 8.314`, `N_A = 6.022e23`, `MW_AIR_KG_PER_MOL = 0.0289`) pinned to the Fortran values — not CODATA — so round-trip tolerances stay in single-ULP territory. Also `box_air_mass_kg(boxvol, T, P)` as a sanity-check helper. NumPy-array inputs supported via `np.asarray`. 19 unit tests include line-by-line parity checks against the Fortran formulas.
- Ruff config adds `RUF002` / `RUF003` to the ignore list — unicode markup (`×`, `↔`, `²`, `³`, `⁻¹`, `—`) is deliberate in docstrings and not an ambiguity hazard.
- **C0.3 — species-name parser**: `atmos_jax_common.species` provides `parse_species_name`, `format_species_name`, `is_som_species`, and a frozen `SpeciesIdentifier` dataclass. Recognises `FAMILY_CC_OO` strings (uppercase family starting with a letter; two-digit zero-padded C and O). 39 unit tests cover parsing, formatting, round-trips, rejection of invalid inputs, hashability, and the full 40-species GENSOMG and 47-species AR1SOMG grids from the Fortran reference. Total: 60 tests pass.
- **C0.4 — Fortran runner**: `atmos_jax_common.fortran_runner` wraps the `make -f simple_makfile` + `./box.exe < input` command-line workflow into a typed Python API. `build(src_dir)` compiles (runs `make clean` first by default, since `som-tomas-app/src` ships 2022-era Linux `.o` files that defeat incremental linking on other architectures). `run(src_dir, input_text)` allocates a scratch directory with symlinked source + fresh `outputs/`, executes `./box.exe`, and returns a typed `RunOutputs` with the nine output files (`.dat`, `_gc.dat`, `_noconc.dat`, `_aemass.dat`, `_spec.dat`, `_saprcgc.dat`, `_vl.dat`, `_tau.dat`, `_kw.dat`). Custom `FortranBuildError` / `FortranRunError` exceptions bubble stderr and exit codes. Integration tests gated by `SOM_TOMAS_APP_SRC` env var + `gfortran` on PATH — 8 tests exercise build, run, multi-run scratch isolation, and error paths; skip cleanly in CI without the Fortran toolchain.
- **C0.5 — real4 downcast helper**: `atmos_jax_common.real4.downcast_to_real4(x)` round-trips a value through `float32` and back to `float64`, mimicking the precision loss of Fortran `REAL*4` output. Companion `with_real4_precision(a, b)` aligns two arrays to the same lossy precision before a diff; `real4_epsilon()` returns `np.finfo(np.float32).eps` as a lower bound on meaningful relative-error tolerances. 17 unit tests cover exact survival, ULP-level collapse, inexact-decimal drift, NaN/±∞ pass-through, subnormal preservation, underflow-to-zero, and overflow-to-∞ edge cases.
- **som-tomas-fortran submodule + CI integration**: vendored the Fortran reference as a git submodule at `third_party/som-tomas-fortran/`. Integration tests now default to the submodule source; override via `SOM_TOMAS_FORTRAN_SRC` (the legacy `SOM_TOMAS_APP_SRC` still works with a deprecation warning). CI gained a dedicated `integration` job that installs `gfortran` on Linux, checks out submodules, builds `box.exe`, and runs `pytest tests/integration` — the Fortran reference is now tested on every PR. Ruff `extend-exclude = ["third_party"]` keeps the submodule's Python scripts out of our lint scope. Total: **85 tests pass** (13 integration tests + 72 unit tests) on `macOS` locally with the submodule populated.
- **C0.6 — goldens loader**: `atmos_jax_common.goldens` parses Fortran output files into typed numpy arrays. `load_golden_run(outputs_dir, run_name)` returns a `GoldenRun` dataclass bundling: `gc` (`_gc.dat`, time-major SOM gas-phase concentrations), `saprcgc_ppm` (full SAPRC active-species ppm; no time column — aligns with `gc.time_hours` by Fortran-write convention), `noconc` (per-bin number concentration), `aemass_kg` (3-D `(n_timesteps, n_aerosol_species, n_bins)` aerosol mass), and `spec` (rich `SpecMetadata`: active gas species list, SOM species names, per-species C / O counts, MW / MW_HC / MWORG, c\* / Hvap / Pstar). Lower-level entry points: `load_block_file()` for time-major files, `load_saprcgc_file()` for the no-time-column SAPRC matrix, `load_spec_file()` for the labeled metadata. Sample run committed as test fixtures under `tests/fixtures/sample_run/` (~80 KB total). Total: **106 tests pass** (26 new for the loader + 80 pre-existing).
- **C0.7 — compare primitives**: `atmos_jax_common.compare` provides tolerance-aware trajectory comparison: `relative_l2(a, b)` per-species relative L2 (atol-floored to keep zero-reference columns finite), `per_species_correlation(a, b)` Pearson per column (returns 1.0 by convention for constant columns to avoid NaN propagation), `final_time_error(a, b)` last-row absolute and relative error, plus `carbon_balance(conc, carbon_counts)` and `carbon_balance_drift(conc, carbon_counts)` for conservation sanity. `compare_trajectories(a, b, names)` bundles all three metrics into a `DiffReport` dataclass with `passes(l2_tol=, correlation_min=, final_rel_tol=)` (defaults track the master plan's ≤0.1% / ≥0.999 faithfulness bar), `worst_species(by=...)`, and `summary()` for human-readable error output. 23 unit tests cover identity / scale / zero / shape / correlation edge cases (constant column, anti-correlation, ULP-level floating-point clamp), `carbon_balance` linearity, conserving-vs-lossy drift detection, and `DiffReport` threshold overrides. Total: **129 tests pass**.
- **atmos-jax-common figures retrofit (C0.6 + C0.7)**: backfilled matplotlib diagnostics for the goldens loader and compare primitives. `scripts/make_c0.6_figures.py` renders a 4-panel overview of a parsed `GoldenRun` (gas-phase trajectories, per-bin number concentration, total aerosol mass, SOM (C, O) grid coloured by c\*). `scripts/make_c0.7_figures.py` renders a `DiffReport` demo: synthetic Fortran-vs-JAX comparison with one biased species, showing the per-species L2 bar chart with tolerance line and the worst-species overlay. Adds matplotlib (`>=3.8`) to `[project.optional-dependencies].dev`; ruff per-file ignore for `scripts/make_*_figures.py`.

- **C0.8 — canonical-run matrix (v0.1)**: `data/canonical_runs/manifest.json` defines a 10-run matrix that covers the gas-phase chemistry coverage space (time scale, OH dose, GENVOC magnitude, temperature). Each run is a deterministic configuration of `box.exe` rendered into a committed `data/canonical_runs/inputs/<run_id>.txt` stdin file. The `atmos_jax_common.canonical_runs` module provides the typed loader (`load_manifest`, `CanonicalMatrix`, frozen dataclass tree) and the box.f-format renderer (`render_input`); 17 unit tests cover schema validation, duplicate-id rejection, deterministic rendering, and committed-vs-manifest drift. Matrix axes: 4 endtimes (10 min → 24 h), 3 OH levels (5×10⁵ → 5×10⁶), 3 GENVOC levels (0.005 → 0.5 ppm), 3 temperatures (273, 298, 323 K). Matrix design is open to revision when master plan Q5 lands.

- **C0.9 — goldens generator + drift checker**: `scripts/generate_goldens.py` reads the manifest, builds the Fortran reference (or accepts `--skip-build`), runs every entry through `box.exe`, and writes outputs into `data/canonical_runs/expected/<run_id>/`. Each run gets a `metadata.json` recording the input SHA-256, per-Fortran-source-file SHA-256s, the submodule commit, and a UTC timestamp. The `--check` mode regenerates into a temp dir and byte-diffs against committed (excluding the timestamp from the diff) so CI can detect Fortran drift cheaply. `scripts/regenerate_canonical_inputs.py --check` does the same for the input files vs the manifest. Committed goldens occupy ~8.5 MB across 110 files; full regeneration takes ~32 s on macOS.

- **C0.8 figure**: `docs/figures/c0.8/matrix_coverage.png` — top: scatter of all 10 runs in the (endtime_h, OH) plane with marker size encoding GENVOC and colour encoding temperature; bottom: GENVOC trajectory per run drawn from the committed `_saprcgc.dat`. Visual proof that the matrix covers the intended axes.

- **C0.10 — mechanism-drift CI guard**: two new CI jobs in `.github/workflows/ci.yml`. (1) `canonical-inputs` runs on Ubuntu and verifies the committed input files match the manifest via `regenerate_canonical_inputs.py --check`. (2) `mechanism-drift` runs on macOS (the only platform where `box.exe` runs cleanly until upstream U1 lands), brew-installs gfortran, and runs `generate_goldens.py --check` against the committed goldens. Any Fortran source change that drifts an output, or any committed-file mutation, fails CI immediately on PR.

### Changed
- **Sample-run fixture refresh — REAL\*8 INTEGR2 build**: bumped `third_party/som-tomas-fortran` to a build that promotes the `INTEGR2` chemistry path (working arrays, the `DIFF` callback, `SAPRCGC` storage, `TIN`/`TOUT`) from `REAL*4` to `REAL*8` and tightens the predictor/corrector convergence criterion (`E3`) from `1e-3` to `1e-10`. Regenerated `tests/fixtures/sample_run/` from this build using the same input as before (10-min gas-phase-only run, GENVOC = 0.05 ppm, OH = 1.5×10⁶ molec/cm³, T = 298 K, P = 101325 Pa, no aerosol, no wall losses). Cascade-species `_saprcgc.dat` values shift up by 4-22% relative to the previous loose-Fortran fixture; this matches the JAX/diffrax double-precision reference at `rtol=1e-10` to within ~0.3% median across 35+ species. `_kw.dat` is bit-identical (single zero row); `_aemass.dat`, `_gc.dat`, `_noconc.dat`, `_saprcgc.dat`, `_spec.dat`, `_tau.dat`, `_vl.dat` all updated. Regenerated C0.6/C0.7 figures so the visuals reflect the new fixture.
